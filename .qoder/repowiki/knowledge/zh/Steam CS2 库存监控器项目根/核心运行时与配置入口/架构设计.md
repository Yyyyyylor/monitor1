本模块由三个职责清晰的文件组成：
- `main.py` 是异步 CLI 入口，通过 `asyncio.run(main())` 启动事件循环，依次执行数据库初始化、健康检查服务启动、注册两个 APScheduler 定时任务（监控间隔与每日维护），并处理 SIGINT/SIGTERM 信号实现优雅关闭。
- `config.py` 使用 `pydantic_settings.BaseSettings` 从 `.env` 加载全部应用配置，提供 `steam_id_list` 等派生属性，暴露全局单例 `settings` 及 `DATA_DIR`。
- `utils.py` 提供通用工具函数，核心是 `setup_logging`，将 loguru 作为主日志后端，同时桥接标准 `logging` 模块输出到同一管道。
依赖方向单向：`main.py` → `config` / `utils` → 其他子模块（db、scheduler、health、crawler），通过延迟 import 避免循环导入。
